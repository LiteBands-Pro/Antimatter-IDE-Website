# Antimatter website

Open-source landing page and docs for [Antimatter](https://github.com/ComicalSoftwares/Antimatter).
Plain HTML, CSS and JavaScript in one file, no build step, no trackers. MIT licensed.

- `index.html` is the whole site. Host it anywhere static.
- Docs: fetched live from the GitHub wiki (raw.githubusercontent.com) and rendered natively, with an embedded snapshot as an offline fallback.
- Download button: reads the latest GitHub release on Windows, opens the Linux build docs on Linux, and is disabled on other systems.
