A modern, lightweight and absurdly optimized Python IDE.

Written in Python and PyQt6. No telemetry, low resource usage, a very snappy UI, and issues shown only when you ask for them.

DownloadView on GitHub

Features

Edit and run Python

Open, save and run scripts, with or without the debugger.

Build templates

Compile scripts with automated build templates.

Zero telemetry

Complete privacy. Nothing leaves your machine.

Custom code viewer

A fully custom backend with syntax highlighting that loads multiple large scripts in seconds.

Issues on demand

Pyflakes finds what could stop a script from launching, only when you want to see it. No annoying popups.

Live terminal

An integrated terminal, one shortcut away.

Discord Rich Presence

Powered by pypresence.

Clean interface

Distraction-free, with a simple wiki and documentation.

Requirements

Pyflakes for finding issues.

Python 3.14 recommended. Any 3.x works; Python 2.x will corrupt your files.

Windows or Linux. Other OSes can build from source, without support.

A compiler (optional) such as PyInstaller or Nuitka for shipping apps.

Open source

Antimatter is free and open-source. So is this website.

The IDE is MIT-licensed. The docs on this site are rendered live from the project’s GitHub wiki, and the site itself is plain HTML, CSS and JavaScript with no build step and no trackers. Read it, fork it, fix it.
